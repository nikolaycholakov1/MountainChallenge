If this were my project...

I'd keep it as a single HTML file but make it feel like a polished web app. My roadmap would be:

🗺️ Interactive map
📷 Photo gallery for completed peaks
📈 Rich statistics (total ascent, average height, etc.)
🔍 Search and filters
🏅 Achievement system
💾 LocalStorage so you never edit the HTML again

Those six features would transform it from a checklist into a personal digital hiking journal that's enjoyable to revisit after every trip.
